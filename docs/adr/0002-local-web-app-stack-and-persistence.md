# Local Web App Form Factor, TypeScript/Node Stack, and Local Persistence

Status: accepted

Unified Marketplace Search v1 will run as a single-user **localhost web app** bound strictly to `127.0.0.1` (default port `4173`, overridable via `UMS_PORT`) built as a single-package **TypeScript on Node.js 24+** (`npm`) repository pairing a **React + Vite + Tailwind CSS** SPA frontend with a **Hono** (`@hono/node-server`) backend, **Zod** runtime validation, and **Vitest** tests. Built-in `fetch` drives eBay's Buy Browse API, while **`patchright`** standardizes Chromium automation across Poshmark, Mercari US, and Facebook Marketplace against the three isolated Chrome/Edge profiles established in ADR-0001. All persistent runtime state lives under `%LOCALAPPDATA%\unified-marketplace-search\` on Windows (`UMS_DATA_DIR` override; XDG fallback on non-Windows): **Saved Searches**, **Watchlist Entries**, and non-secret app settings in a single `data.sqlite` accessed through thin typed repositories over built-in **`node:sqlite`** (`DatabaseSync`, `WAL` mode, `PRAGMA user_version` migrations), eBay API credentials in an untracked `secrets.json` (with optional env-var overrides), cached **Watchlist Entry** thumbnails in `thumbnails/`, and dedicated browser profiles in `profiles/{facebook,poshmark,mercari}/`.

## Considered Options

- **Electron or Tauri desktop shell (`.exe`):** Adds desktop packaging, installer, and IPC complexity without eliminating separate installed Chrome/Edge processes required by ADR-0001; Tauri additionally requires installing Rust plus a separate Node/Python sidecar.
- **Python backend (`patchright-python`/`nodriver`) + TypeScript frontend:** Requires installing Python and maintaining two runtimes, package managers, and schema layers when Node.js (`v25.9.0`) is already installed locally and `patchright` ships a first-class Node.js/TypeScript package.
- **Full-stack SSR framework (Next.js / SvelteKit) or multi-package monorepo:** SSR hydration boundaries and dev HMR module reloads conflict with long-lived stateful `patchright` browser managers, exclusive profile locks, and local SQLite handles.
- **Plain JSON files or an ORM / native SQLite addon (`better-sqlite3`, Prisma, Drizzle):** Plain JSON adds concurrency and uniqueness boilerplate for background thumbnail-cache updates on **Watchlist Entries**, while native C++ SQLite addons risk Windows `node-gyp` build issues and ORMs are overbuilt for three small tables (`saved_searches`, `watchlist_entries`, `app_settings`).
- **Repo-local `./data/` folder and Windows DPAPI / Credential Manager encryption:** Keeping Chrome profiles and credentials inside the repo risks accidental commits or OneDrive sync, while DPAPI/Credential Manager adds Windows-only PowerShell or native keyring wrappers unnecessary for a single-user local-first v1.

## Consequences

- **Runtime floor & zero native builds:** Targeting **Node.js 24+** unlocks warning-free built-in `node:sqlite`, avoiding C++ build toolchains on Windows while staying OS-portable where free.
- **Single-origin local server & browser lifecycle:** The Hono server serves static frontend assets, `/api/*`, cached **Watchlist** thumbnails, and optional SSE search streams on `127.0.0.1`. Browser contexts launch lazily per **Marketplace** (never on app startup) using headless background Chrome (`headless: true`, `--window-size=1280,900`, with non-`HeadlessChrome` User-Agent, verified unthrottled on Windows without taskbar flashing or stealing focus), stay warm briefly with idle auto-close, enforce exclusive per-profile locking (closing any background context before opening an explicit on-screen foreground `"Open browser session"` window at `--window-position=80,80 --window-size=1280,900` to avoid Windows `SingletonLock` collisions and persisted off-screen placement), and tear down cleanly on `Ctrl+C` or in-app **"Stop server"**. `secrets.json` stores eBay credentials under `{ "ebay": { "client_id": "...", "client_secret": "..." } }`.
- **Lightweight Windows launch & Settings UX:** Startup stays strictly on-demand via `npm start` or a double-clickable `start-ums.cmd` shortcut that auto-opens the browser (or points to the already-running instance) with no Windows installer, auto-start service, or system tray wrapper. An in-app **Settings** panel manages eBay `client_id`/`client_secret` (never returning raw `client_secret` from `GET` endpoints), Chrome/Edge channel selection, data directory visibility, Home ZIP/radius plus optional **Home Facebook City Slug**, and per-**Marketplace** `"Open browser session"` / profile reset controls.
