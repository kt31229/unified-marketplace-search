# Unified Filter Schema, Facebook 500-Mile Multi-City Coverage, and Two-Tier Filter Translation

Status: accepted

Unified Marketplace Search v1 will require non-empty `keywords` (passed through verbatim without a custom query-operator DSL) paired with a lean **Unified Filter** schema (`priceMin`/`priceMax` in USD base **Listing** price, 5 multi-select `Condition` tiers `new`/`like_new`/`good`/`fair`/`poor`, 3 `Fulfillment` modes `any`/`shipping`/`local_pickup`, customizable **Facebook City Hubs** seeded with a verified 8-city 500-mile US Nationwide preset `seattle`/`sanfrancisco`/`la`/`denver`/`dallas`/`chicago`/`atlanta`/`nyc`, and local pickup ZIP/radius plus optional **Home Facebook City Slug**), 4 universal sort options (`relevance`, `newest`, `price_asc`, `price_desc`), active-only **Listings**, and `buyingOptions:{FIXED_PRICE|AUCTION}` always enabled on eBay. **Unified Filters** translate into **Marketplace Filters** under a two-tier degradation policy returning per-**Marketplace** translation diagnostics (`exact`, `broadened`, `skipped_unsupported`): completely unsupported strict constraints (such as `Fulfillment = local_pickup` on Poshmark or Mercari US) skip that **Marketplace** with a clear UI notice, whereas coarser **Marketplace Filters** (such as `poor` mapped to `uf` on Poshmark or `used_fair` on Facebook, category-general `Used` `3000` alongside live `20xx` refurbished IDs `2010`/`2020`/`2030` on eBay, or Facebook `Fulfillment = local_pickup` using **Home Facebook City Slug** with the profile's saved browse radius when `localPickupRadiusMiles` differs from the profile's 500-mile sweep setting) query the broadest valid superset and surface a `"broadened"` badge.

## Considered Options

- **Structured Size, Category, Brand, Color, Date Listed, or Free Shipping Unified Filters in v1:** Omitted because none of the four **Marketplaces** supports cross-category size filtering (eBay `aspect_filter` requires a leaf `category_ids` and category-specific aspect names; Mercari uses drifting numeric `sizeIds`; Facebook has no general URL size parameter; Poshmark scopes `size[]` by department), category/brand/color IDs are incompatible across **Marketplaces**, and silently injecting short size strings like `"M"` into `keywords` causes noisy false matches. Users include size, brand, color, or category terms directly in `keywords`.
- **Treating Facebook's 500-mile city radius as a strict local-only filter that skips Poshmark and Mercari:** Rejected because buyers routinely message Facebook local-pickup sellers anywhere in the US to arrange paid shipping. Instead, Facebook's customizable 500-mile city hub list (`seattle`, `sanfrancisco`, `la`, `denver`, `dallas`, `chicago`, `atlanta`, `nyc`, `facebookRadiusMiles: 500` profile default) serves as Facebook's nationwide coverage mechanism under `Fulfillment = any`, while Poshmark and Mercari are only skipped when `Fulfillment = local_pickup` is explicitly selected for in-person pickup.
- **Mapping eBay `like_new`, `good`, and `fair` strictly to granular `conditionIds` (`1500`/`4000`/`5000`/`6000`) without `3000` (`Used`):** Rejected because major eBay categories (including Clothing, Home, and Sporting Goods) use `3000` as their sole pre-owned condition ID and would return zero pre-owned **Listings** if `3000` were omitted. eBay's `like_new` and `good` mappings also include live `20xx` refurbished sub-IDs (`2010` *Excellent - Refurbished* and `2020` *Very Good - Refurbished* in `like_new`; `2030` *Good - Refurbished* in `good`) alongside `1500`/`2000`/`2500`/`2750`/`3000`/`4000`/`5000`.
- **Automating Facebook's in-page radius picker per `local_pickup` search:** Rejected because Facebook persists browse radius at the profile level (`805 km` / `500 mi`) with no verified `?radius=` URL parameter; automating the UI picker per search adds fragile selectors and extra mutation traffic against the signed-in account, so `local_pickup` uses **Home Facebook City Slug** with the profile's saved browse radius and a `broadened` notice instead.
- **Allowing filter-only searches with empty `keywords`:** Rejected (tightening the earlier **Saved Search** creation rule) because eBay's Buy Browse API requires `q` when `category_ids` is absent.

## Consequences

- **Sequential multi-city Facebook sweeps under ADR-0001 guardrails:** When multiple Facebook City Hubs are enabled on a search, the Facebook adapter must query them sequentially in a single tab with mandatory cooldowns (per ADR-0001), stream **Listings** progressively, and deduplicate overlapping 500-mile circles by `(marketplace: 'facebook', marketplaceListingId)`.
- **Transparent per-Marketplace translation notices:** Every adapter translation outputs structured status (`exact` | `broadened` | `skipped_unsupported`) and human-readable reasons so the consolidated UI can explain why Poshmark/Mercari were skipped on a `local_pickup` search or why Poshmark (`poor` → `uf`), eBay (`3000` general `Used`), or Facebook (`poor` → `used_fair`; `local_pickup` using the profile's saved browse radius) broadened a selection.
- **Tightened Saved Search validation:** Both live searches and **Saved Searches** require non-empty trimmed `keywords` and at least one enabled **Marketplace**.
- **Live-verified 2026 Marketplace Filter syntax:** Mercari US sends `minPrice`/`maxPrice` in integer cents (`Math.round(dollars * 100)`) and `shippingPayerIds=2` for Free Shipping; Poshmark uses native 4-tier conditions (`nwt`, `uln`, `ug`, `uf`) passed as repeated `condition=<val>` query params (e.g., `condition=nwt&condition=uln` on `/search` and `filters.condition: ["nwt", "uln"]` on `/vm-rest/posts`), `price[]=<min>-<max>` on `/search` and `filters.price_amount_range: [{ min?: { val: "<dollars>", currency_code: "USD" }, max?: { val: "<dollars>", currency_code: "USD" } }]` (in USD dollars, not cents) on `/vm-rest/posts`, `sort_by=relevance_v2|added_desc|price_asc|price_desc`, and `shipping_discount_type=free|discounted`; Facebook uses verified hub slugs (`seattle`, `sanfrancisco`, `la`, `denver`, `dallas`, `chicago`, `atlanta`, `nyc`), `deliveryMethod=shipping` (or `deliveryMethod=local_pick_up`), and profile-persisted `805 km` (`500 mi`) radius; eBay includes `2010`/`2020` in `like_new` (`{1500|2000|2010|2020|2500|2750|3000|4000}`) and `2030` in `good` (`{2030|3000|5000}`), plus `X-EBAY-C-ENDUSERCTX` for optional Home ZIP shipping context.
